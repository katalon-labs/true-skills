# Contributing to True Skills

Thanks for improving the Katalon True Platform skills. The golden rule keeps this repo sane:

> **Edit `skills/` only. Everything else is generated.**

## How it works

`skills/<name>/SKILL.md` (plus its `references/*.md`) is the single source of truth for each workflow. The build script reads `skills/` and writes the native config for every supported agent:

- `plugins/katalon-true-platform/` - Claude Code + Codex plugin (and the root `.claude-plugin/` / `.agents/` marketplaces)
- `.cursor/rules/` - Cursor
- `.kiro/steering/` - Kiro
- `.github/prompts/` + `.github/copilot-instructions.md` + `.vscode/mcp.json` - GitHub Copilot
- `.windsurf/rules/` - Windsurf
- `.clinerules/` - Cline
- `.continue/` - Continue
- `AGENTS.md` and `.mcp.json` - universal fallback

Every generated file carries a `GENERATED by scripts/build-adapters.mjs` banner. Do not hand-edit them - your change will be wiped on the next build.

## Workflow

1. Edit a skill under `skills/`. Keep the body **agent-neutral** (say "you" or "the agent", never a single product name).
2. Regenerate:
   ```bash
   node scripts/build-adapters.mjs
   ```
   Requires Node >= 18. No dependencies to install.
3. Commit `skills/` **and** the regenerated files together.

## Adding a new skill

1. Create `skills/<new-name>/SKILL.md` with YAML frontmatter (`name`, `description`) and any `references/`. The frontmatter `name` must equal the folder name.
2. Add an entry for `<new-name>` to the `INTERFACE` map and the `ORDER` array in `scripts/skills.config.mjs`.
3. Validate, rebuild, and commit:
   ```bash
   node scripts/validate-skills.mjs
   node scripts/build-adapters.mjs
   ```

`validate-skills.mjs` fails if a `skills/` folder is missing from `INTERFACE`/`ORDER` (or vice versa), if frontmatter is missing, if a folder name and its `name` disagree, or if a real Katalon subdomain leaks into a skill body. It runs in CI before the build.

## Adding a new agent

Add a generation block to `scripts/build-adapters.mjs` that writes the agent's native format, then document the install path in `README.md`. Keep generation deterministic (no timestamps, sorted output) so the build stays idempotent.

## Checks

CI runs the validator, then the build, and fails if the working tree changes - i.e. if generated files are out of sync with `skills/`. Run both locally before pushing:

```bash
node scripts/validate-skills.mjs && node scripts/build-adapters.mjs && git diff --exit-code
```

## Conventions

- **No secrets, ever.** Skills must never instruct a user to paste passwords, tokens, cookies, JWTs, MFA codes, or OAuth callback URLs into chat.
- **Be honest about boundaries.** If the Katalon MCP can't do something, the skill says so and offers the supported workaround.
- The only real MCP endpoint allowed in the repo is the canonical shared host `https://platform.katalon.io/mcp` (allowlisted in `validate-skills.mjs`). For anything that varies per customer, use the `https://<your.sub.domain>.katalon.io/mcp` placeholder - never commit a real per-workspace subdomain.
