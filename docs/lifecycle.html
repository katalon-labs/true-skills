What it is

One well-tested set of Katalon True Platform testing skills that any AI coding agent - and any model tier, from the largest models down to small ones - can run. Every step of the software testing workflow, from plan to insight, is covered by a skill mapped to concrete Katalon MCP tools. The lifecycle router picks the right stage; the loop closes when maintenance feeds gaps back into planning.

CROSS-CUTTING

Connect & route

katalon-platform-setuptrueplatform-testing (router)
Connect and verify the MCP · route any request to the right stage · run the full chain end to end.

↺ The loop closes: stage 7 Maintain feeds the refreshed coverage gap list back into stage 1 Plan.

Some steps are product surfaces (Studio, TestOps UI, TrueTest), not MCP calls - each skill states its boundary so the agent never over-promises.

Runs on any agent, any model

  • Deterministic: numbered tool order and explicit stop conditions, so smaller models follow the steps instead of guessing.
  • Agent-neutral: MCP tools referenced by platform name only - the same skill body works in Claude Code, Codex, Copilot, Cursor, Kiro, Windsurf, Cline, and Continue.
  • Bounded: every skill states what the MCP can and cannot do up front, so no agent hallucinates create-requirement, create-release, or self-healing.
